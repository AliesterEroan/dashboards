## 🌟 Welcome!

Collection of web-based dashboards for data visualization, monitoring, and interface design.

## 🎯 What's Inside?

### 📊 Web Interface
- **dashboard.html** - Main dashboard interface
- **Data.html** - Data display and management

### 🧪 Testing Web
- **dashboard.html** - Testing dashboard version
- **Testing 1.html** - Additional testing interface

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling and layout
- **JavaScript** - Interactivity and data handling
- **Responsive Design** - Mobile-friendly interfaces

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/AliesterEroan/dashboards.git
   ```

2. **Open a dashboard**
   - Navigate to the desired folder
   - Open HTML file in web browser
   - View and interact with the dashboard
